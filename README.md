# UDP数据发送模拟器

这是一个基于Web的UDP数据发送模拟工具，用于模拟设备状态数据的UDP发送。该工具使用WebSocket作为中转，将网页端的数据通过UDP协议转发到指定目标。

## 系统架构

```
[浏览器] <--HTTP--> [本地Web服务器:5500]
   |
   +--WebSocket--> [WebSocket服务器:172.17.102.222:8081]
                      |
                      +--UDP--> [UDP目标设备]
```

## 功能特点

- 可配置的UDP目标地址和端口
- 可调节的数据发送间隔
- 支持多种驾驶模式设置
- 实时显示数据包内容
- 支持工作时长和里程统计
- 电量和速度实时调节
- 数据包内容实时预览

## 数据包格式

数据包总长度为17字节，采用大端序（Big-Endian）格式：

| 字节位置 | 长度 | 说明 | 取值范围 |
|---------|------|------|----------|
| 0       | 1    | 帧类型 | 固定为0x86 |
| 1-2     | 2    | 生命信号 | 0-65535 |
| 3       | 1    | 驾驶模式 | 0:人工, 1:遥控, 2:远程, 3:演示, 4:其他 |
| 4-7     | 4    | 工作时长 | 0-4294967295（小时）|
| 8-11    | 4    | 运行里程 | 0-4294967295（千米）|
| 12-13   | 2    | 当前位置 | 0-65535（米）|
| 14-15   | 2    | 速度 | 0-65535（0.01m/s）|
| 16      | 1    | 电量 | 0-100（%）|

## 安装说明

1. 安装Node.js（建议版本 >= 14.0.0）

2. 安装项目依赖：
   ```bash
   npm install
   ```

## 使用方法

1. 启动WebSocket服务器：
   ```bash
   node server.js
   ```
   服务器将在8081端口启动

2. 启动Web界面：
   - 使用VS Code的Live Server插件
   - 或者使用其他HTTP服务器托管index.html

3. 在浏览器中访问：
   ```
   http://127.0.0.1:5500/index.html
   ```

4. 配置参数：
   - UDP目标IP（默认：172.17.102.218）
   - UDP目标端口（默认：10086）
   - 发送间隔（默认：100ms）
   - 其他参数根据需要调整

5. 点击"开始发送"按钮开始发送数据

## 配置说明

### WebSocket服务器
- 地址：172.17.102.222
- 端口：8081
- 在server.js中配置

### 默认UDP目标
- IP：172.17.102.218
- 端口：10086
- 可在页面中实时修改

### 参数范围
- 工作时长：0-4294967295小时
- 运行里程：0-4294967295千米
- 当前位置：0-65535米
- 速度：0-655.35m/s
- 电量：0-100%

## 注意事项

1. 确保WebSocket服务器（server.js）正常运行
2. 确保UDP目标地址可达
3. 建议使用Chrome或Firefox浏览器
4. 数据发送间隔不建议小于100ms

## 开发说明

- 前端：原生JavaScript + WebSocket
- 后端：Node.js + ws模块 + dgram模块
- 数据格式：ArrayBuffer + DataView

## 错误处理

1. WebSocket连接失败：
   - 检查服务器地址和端口
   - 确认server.js是否运行

2. UDP发送失败：
   - 检查目标地址和端口
   - 确认网络连接状态
